# Roo Code project rules

Follow `AGENTS.md` for shared project rules. For game-development tasks, read
`.opencode/skills/universal-game-development-engineer/SKILL.md` and the relevant
references before implementation.

Inspect the installed engine and existing architecture first. Discover MCP tools
at runtime, preserve user work, verify asset licenses, and run focused tests.
Report configured, implemented, compiled, tested and verified outcomes
separately. Never fabricate tools, screenshots or test results.
