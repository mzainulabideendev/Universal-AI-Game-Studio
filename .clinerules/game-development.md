# Cline project rules

Follow `AGENTS.md` for shared project rules. For game-development tasks, read
`.opencode/skills/universal-game-development-engineer/SKILL.md` and the relevant
references before implementation.

Inspect the installed engine and project before editing. Discover MCP tools at
runtime, preserve existing work, verify asset licenses, and test the changed
behavior. Distinguish configured, implemented, compiled, tested and verified
work. Do not invent tools, screenshots, test output or build results.
