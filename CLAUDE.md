# Claude Code project guidance

Follow the shared instructions in [`AGENTS.md`](./AGENTS.md). For game
development tasks, read the core workflow at
`.opencode/skills/universal-game-development-engineer/SKILL.md` and the relevant
reference before implementation.

Inspect the existing engine, project structure, tool versions and tests first.
Preserve user work, verify asset licenses, and report configured, implemented,
compiled, tested and verified work separately. Do not invent tool availability,
gameplay, screenshots or test results.
