# Gemini CLI project guidance

Follow [`AGENTS.md`](./AGENTS.md) for shared project rules. For game-development
work, read
`.opencode/skills/universal-game-development-engineer/SKILL.md` and the
references relevant to the task.

Inspect the installed engine and project before editing. Discover MCP tools at
runtime, preserve existing work, verify asset licenses, and run focused tests.
Report configured, implemented, compiled, tested and verified outcomes
separately. Never claim a build or gameplay is verified without actually
launching it and checking logs.
